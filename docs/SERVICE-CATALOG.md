## 核心约定

- **所有以下合法技术服务均可展示并接收需求咨询**；“能咨询”不等于已经接到订单或保证任意环境能交付。
- 服务标记 **S**：可制定明确范围的标准套餐；正式售卖前确认最小案例、真实交付内容及支持期。
- 服务标记 **C**：可借助 AI、开源和自动化完成的定制项目；需求和技术可行性评估后报价，必要时先进行付费 PoC。
- 服务标记 **R**：涉及重大数据、安全、性能或工业控制的情境，仅承接授权范围内的评估；高风险实施另行评审或不承接。
- 你购买的是被审核、测试、交付的成果；AI 是开发工具，不是对未验证结果的无限担保。

**说明：** 此处的服务数量是候选能力目录，不代表 68 项都曾完成商业交付。具体项目以合同与验收为准。

- 可以说：“承接 Spring Boot / React / AI Agent / RAG / ThingsBoard / MQTT 等需求分析、开发和技术集成，支持 AI 辅助开发，根据复杂度报价。”
