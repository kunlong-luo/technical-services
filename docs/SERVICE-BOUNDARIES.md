# 服务边界与售前准入 V1.0

更新：2026-11-23。**全部服务方向可接受咨询，能否承接具体项目按范围、风险、资源、授权及验收标准决定。** 公开范围不代表已获厂家官方认证或通过实际生产验收。

## 风险和准入

| 等级 | 典型场景 | 商业方式 | 核心边界 |
| --- | --- | --- | --- |
| L1 低风险 | 静态网站、页面修复、单个脚本、单机开发环境、单接口 | 有明确边界的标准套餐或小定制 | 不保证任意环境、无限次修改或超出范围的故障修复 |
| L2 中风险 | 企业后台、App/小程序、数据库 SQL 优化、RAG、MQTT 模拟设备接入 | 需求评估后分阶段报价，必要时 PoC | 不保证未测性能、第三方审核或全设备兼容 |
| L3 高风险 | 生产数据迁移、支付/库存一致性、K8s 生产可用性、真实工业控制、敏感数据处理 | 先付费评审；有授权、备份、恢复计划和适当资质才考虑实施 | 不承诺绝对无损、零停机、永久可用、未经批准的远程写控制 |

## Web / App / 企业系统

明确页面、角色、接口、源代码归属、部署和第三方依赖。App 上架、小程序审核、支付商户开通、短信/地图/支付 API 的可用性受相应平台约束，不将审查结果写成保证。复杂 ERP/商城按模块和里程碑定价，不用“一口价包含全部功能”。

## 数据库 / Linux / 生产环境

诊断服务和实际修复分开计价。生产变更必须核实授权、备份与恢复、变更窗口、系统依赖和风险接受方；禁止使用未经审查的 AI 脚本直接修改生产数据。大规模迁移、灾难恢复、核心资金系统不能以简单套餐承诺。

## AI / 自动化 / 内容

明确模型厂商、API 费用、调用额度、输入输出、可接受错误率、评测集、失败处理、数据使用授权、第三方素材和内容版权。可出售 AI 编程和原创图文/视频工作流制作，但不保证模型输出绝对正确、平台流量/销量、版权零争议或第三方服务永久免费。

## 物联网 / ThingsBoard / 工业

明确模拟器、真实只读采集、生产写控制三个不同等级。按设备型号、协议文档、寄存器映射、接入数量、网络/安全环境和版本报价；ThingsBoard / JetLinks / 第三方平台须核对许可证。真实工业控制和安全关键场景须现场授权、专项评审及回退计划，条件不满足时不实施。

## 电脑软硬件

软件安装、开发环境、常见远程诊断可作为标准服务；焊接、芯片级维修、物理数据恢复、复杂主板修复需独立设备和实操证据，不承诺无条件修好。拒绝盗版软件和非法破解业务。

## 每单最低确认

- 工作目标、服务编号、版本、环境与授权范围；
- 交付内容、排除项、价格与第三方费用、售后时间；
- 需求变更处理、交付源码/资产权属、验收条件；
- 数据保密、外部 AI 处理许可、日志/备份与风险说明；
- 不能实现时的诊断产出、取消/退款及争议流程。

**宣传边界：** 不把“懂相关技术”“可借助 AI”“GitHub 有项目”“选择题高分”写成官方认证或已交付特定客户生产系统。
