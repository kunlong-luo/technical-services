## 产品与技术如何关联

PK-04 企业官网 = 设计/页面/联系表单/域名与部署/验收；其内部可组合 WEB、BE、OPS 组件。  
PK-06 预约会员系统 = 页面/后端/数据库/权限/预约流程；其内部可组合 WEB、BE、DB、APP。  
PK-10 设备监控与告警 = 设备数据采集/协议解析/平台/看板/告警；其内部可组合 IOT、TB、DB、WEB。

**客户购买可验收的最终成果；技术模块并不是必须单独买的“零件”。** 专业客户如果只需要其中一个模块，也可以直接提出技术专项需求。

## 价格和状态提示

参考价是试运营测算，不是平台实际成交价。具体服务需要确认设备数、页面数、数据量、第三方许可、环境、需求及售后；不能将最低价描述成任意工作都包修包交付。

- **可咨询**：可以描述需求并要求评估。
- **待专项验证**：需要可复现实验 / PoC / 测试，才能约定交付条件。
- **可签约**：在双方确认范围、授权、价格、验收和支持后才成立具体服务。
- **已真实交付**：必须存在可核对的客户验收证据；当前不以简历/知识题代替。

## 谁维护什么

公开仓库维护客户产品、技术能力、风险边界与获客说明。真实客户线索、实际报价底价、运营进度及测试计划放在私有 `technical-services-ops` 的文档或受控业务系统中；**不将客户真实个人信息、密钥或未经许可的源代码放到 GitHub。**

网站项目及其他代码仓库不属于本轮文档整理范围。
