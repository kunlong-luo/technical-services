## 1. 客户需求与交付承诺

- **目标客户：** 个体商家、小公司、咨询工作室、门店和创业团队
- **典型问题：** 没有正式官网，想展示业务、联系方式和品牌形象，让客户能从手机与电脑打开。
- **客户购买的结果：** 交付一个按需求确认的响应式企业展示网站，并在客户授权的合适托管环境中部署上线、完成基础访问检查与操作交接。
- **服务形式：** 远程/代码交付为优先；需要上门、邮寄或现场的部分必须另外确认服务地区、环境、设备和责任。

## 2.1 售前与上线交付边界（2026-11-24）

- **出售“完整展示网站”的前提**：客户必须明确每一页、区块/文字/图片、联系入口、目标设备/浏览器和修改轮次；所有商业素材需有合法使用授权。
- **基础联系方式只含链接**：拨号/发邮件/现有社交主页等直接链接，不含实际收集、存储用户姓名/电话的联系表单；表单涉及后端、隐私政策/数据留存、反垃圾及安全责任，应另审需求和费用。
- **域名和上线**：域名、托管和合法合规前置不免费附送。只有有合法授权域名/托管、如适用备案和必要上线条件齐备，才能执行真实部署并验证 HTTPS/访问。第三方审核是否通过不作保证。
- **预览≠上线**：缺部署条件时仅可交付预览/静态产物和说明，并事前与客户确认延期/替代交付、费用和验收方式；合同若约定“必须上线”，不得单方把源码/预览视为完整履约。
- **商业状态**：¥1,500/¥3,000/¥6,000 起都是未核价商业假设；已完成 [PK-04 闲鱼文字稿](PK-04-GOOFISH-DRAFT.md)、[私有交付 SOP](https://github.com/kunlong-luo/technical-services-ops/blob/main/docs/PK-04-WEBSITE-DELIVERY-SOP.md)、[空白验收模板](https://github.com/kunlong-luo/technical-services-ops/blob/main/docs/PK-04-ORDER-ACCEPTANCE-PACK.md)。**未执行真实页面开发、浏览器回归、合法域名上线或客户订单。**

## 3. 包含的事项

- 需求确认、内容结构草稿、响应式页面实现
- 客户提供并授权的品牌素材、电话/邮箱/链接等联系入口
- 基本浏览器和移动端检查、代码/部署交接、在客户提供合适域名和托管资源时协助上线

## 4. 不包含事项

- 免费赠送域名、服务器、ICP备案、企业邮箱或第三方 API 费用
- 复杂 CMS、商城交易、支付、会员/后台、自动化营销、持续 SEO 排名保证
- 无限改稿、永久更新、所有浏览器和终端无差别保证

## 5. 客户下单前需要提供什么？

- 品牌名称、业务介绍、授权文字/图片、视觉参考和联系方式
- 预计页面与功能数量、目标客户、交付时间、是否需要后台
- 域名/服务器/部署地域/备案主体由客户确认或另行委托合规办理

## 6. 如何验收？

- 约定页面和区块齐全，文字与素材显示正确
- 手机与桌面端按约定设备/浏览器能正常打开，基本联系入口可用
- 有客户授权的部署环境时完成可访问站点及交接；无必要域名/备案等条件则明确阻碍并调整交付/结算安排

正式交付以双方确认的范围、设备/浏览器与环境、测试结果为准；未知限制须在实施前告知，不能用 AI 生成内容替代验收记录。

## 7. 风险、售后、取消及退款

“官网制作与上线”以客户提供合规托管条件为前提；如果无法提供则不能假称已上线。复杂的联系表单如需收集个人资料，应另行约定后端、反垃圾、隐私政策及存储。修改轮次和缺陷支持期在正式报价前确认。

- **售后建议（待审核）：** 拟考虑对约定范围的交付缺陷设置有限反馈窗口，但“7 天”只是一种商家草拟支持时效，**不是已经核实的闲鱼服务类退款规则**；取消、退款、进度验收与售后应以适用法律、具体平台规则及双方合法约定为准。
- **无法修复或中止：** 区分诊断服务是否已经真实履行、实际修复工作是否开始、客户提供条件是否满足；不得用“虚拟服务概不退款”排除依法应有的权利。必要时按平台规则申请协商或争议处理。
- **AI 与隐私：** 使用 AI 工具必须遵守客户对源码/数据的保密与授权限制；不要求分享账户密码或生产库备份。
