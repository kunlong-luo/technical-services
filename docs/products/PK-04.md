# PK-04｜企业官网 / 品牌展示网站制作与上线（待审核商品草稿 V1.0）

**创建：2026-11-23。状态：可接受需求咨询 / 套餐草稿待验收、待类目核查、未发布。** 本商品卡是拟销售的可验收成果描述，不宣称已有该商品真实客户订单、成功率或通过本次实操。

## 1. 客户需求与交付承诺

- **目标客户：** 个体商家、小公司、咨询工作室、门店和创业团队
- **典型问题：** 没有正式官网，想展示业务、联系方式和品牌形象，让客户能从手机与电脑打开。
- **客户购买的结果：** 交付一个按需求确认的响应式企业展示网站，并在客户授权的合适托管环境中部署上线、完成基础访问检查与操作交接。
- **服务形式：** 远程/代码交付为优先；需要上门、邮寄或现场的部分必须另外确认服务地区、环境、设备和责任。

## 3. 包含的事项

- 需求确认、内容结构草稿、响应式页面实现
- 客户提供并授权的品牌素材、电话/邮箱/链接等联系入口
- 基本浏览器和移动端检查、代码/部署交接、在客户提供合适域名和托管资源时协助上线

## 4. 不包含事项

- 免费赠送域名、服务器、ICP备案、企业邮箱或第三方 API 费用
- 复杂 CMS、商城交易、支付、会员/后台、自动化营销、持续 SEO 排名保证
- 无限改稿、永久更新、所有浏览器和终端无差别保证

## 5. 客户下单前需要提供什么？

- 品牌名称、业务介绍、授权文字/图片、视觉参考和联系方式
- 预计页面与功能数量、目标客户、交付时间、是否需要后台
- 域名/服务器/部署地域/备案主体由客户确认或另行委托合规办理

## 6. 如何验收？

- 约定页面和区块齐全，文字与素材显示正确
- 手机与桌面端按约定设备/浏览器能正常打开，基本联系入口可用
- 有客户授权的部署环境时完成可访问站点及交接；无必要域名/备案等条件则明确阻碍并调整交付/结算安排

正式交付以双方确认的范围、设备/浏览器与环境、测试结果为准；未知限制须在实施前告知，不能用 AI 生成内容替代验收记录。

## 7. 风险、售后、取消及退款

“官网制作与上线”以客户提供合规托管条件为前提；如果无法提供则不能假称已上线。复杂的联系表单如需收集个人资料，应另行约定后端、反垃圾、隐私政策及存储。修改轮次和缺陷支持期在正式报价前确认。

- **售后建议（待审核）：** 对约定范围内的交付缺陷，建议提供交付后 7 天的反馈窗口；诊断咨询仅解释诊断报告，不默认延长修复工时。正式条款须按对应平台规则和双方合法约定确定。
- **无法修复或中止：** 区分诊断服务是否已经真实履行、实际修复工作是否开始、客户提供条件是否满足；不得用“虚拟服务概不退款”排除依法应有的权利。必要时按平台规则申请协商或争议处理。
- **AI 与隐私：** 使用 AI 工具必须遵守客户对源码/数据的保密与授权限制；不要求分享账户密码或生产库备份。
