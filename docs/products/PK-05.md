## 2.2 2026-11-24 独立合成站 HTTP 404 实验（部分实测）

- 已在虚构品牌自有临时站点**实际复现**一个帮助链接 404：Python `GET /` 返回 200，`GET /support.html` 返回 404，确证该合成夹具缺少对应页面文件。
- **诊断 D** 严格只读，源文件修改数为 0，并输出事实/根因/边界的报告；**修复 F** 在独立临时工作副本仅新增 `support.html`，同路径变为 HTTP 200，非目标缺页仍 404；删除新增文件后可回退为 404，首页保持 200。
- [私有 LAB-PK05-01 实验与 SHA 证据](https://github.com/kunlong-luo/technical-services-ops/blob/main/docs/PK-05-LAB-2026-11-24-HTTP404.md) 已留存，源代码、可复验脚本与报告 ZIP **仅存在本次对话附件**，并未写入 GitHub 代码仓库。
- **仅为 PARTIAL-LAB：** 此例证明故意制造的静态 HTTP 404 可以隔离诊断、修复和回退；**不是**真实客户订单、浏览器界面验证、生产网站修复、完整人工工时、平台资格或 ¥99/¥299 已核价。页面调整 U 档没有新增实测证据。

## 2.3 七阶段自动化模拟工单（2026-11-24，仍非真实客户交付）

在原自建 404 故障夹具上生成了独立的**脚本模拟客户工单**，包括模拟询盘/范围、D 只读报告、单独 F **模拟**变更范围、修复与回归、回退和模拟交接清单。[私有完整报告](https://github.com/kunlong-luo/technical-services-ops/blob/main/docs/PK-05-LAB-2026-11-24-MOCK-ORDER-V2.md) 记录了真实本地 HTTP `[200,404] → [200,200,404] → [200,404]` 及 ZIP 解压独立复验。**工单中无真人客户授权、签收或付费**。首次脚本运行 1.524804 秒，只是自动化耗时，**不是客户诊断/修复的人力工时**；¥99/¥299/¥699 全部继续未核价，商品未上架。

## 3. 包含的事项

- 收集授权访问范围、错误截图、浏览器/服务器/项目版本
- 诊断交付证据和建议；修复订单才包含经确认的代码修改

## 4. 不包含事项

- 未经授权渗透、后台访问、爬取客户数据库
- 整站重构、支付/账号安全重大故障、生产数据库修改
- 保证搜索排名、性能 SLA、无限 BUG、第三方服务持续可用

## 5. 客户下单前需要提供什么？

- 网站 URL 或脱敏的本地复现环境、对源码/服务器拥有授权的说明
- 明确一个最重要的问题、复现步骤、报错截图或脱敏日志
- 是否生产环境、可否先在测试环境复现及备份情况

## 6. 如何验收？

- 诊断订单：提供复现/检查记录和下一步建议
- 修复订单：约定问题通过前后对比、功能回归且客户确认
- 变更范围、可见限制、遗留风险、交付的改动说明清晰

正式交付以双方确认的范围、设备/浏览器与环境、测试结果为准；未知限制须在实施前告知，不能用 AI 生成内容替代验收记录。

## 7. 风险、售后、取消及退款

99元诊断价不等于299元及以上的修复价。生产部署与数据库操作须另外授权并具备备份/回滚。若原问题不可复现，按约定输出已完成的调查证据与待补信息。

- **售后建议（待审核）：** 如提供“交付后 7 天问题反馈窗口”，只能是经营者自拟的待审核支持条款，不等于平台已经确认的服务退款规则；诊断订单仅解释已交付的报告，不默认赠送追加诊断/代码修复。正式时效、取消和退款必须以适用法律、具体平台服务类目规则和双方合法约定为准。
