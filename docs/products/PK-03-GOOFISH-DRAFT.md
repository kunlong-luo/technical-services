## 四、客户常见问题（拟上架 FAQ）

**Q：99 元可以装所有开发软件吗？**
A：不能。¥99 仅为单技术栈的拟定入门规格；一台设备、一个约定工具链、Git 和最小测试。最终能否按此价格提供还需完成工时核价。

**Q：199 元能把我手里任何项目都运行起来吗？**
A：不能保证。它是约定的两套工具链及 IDE 的基础配置，含有限的版本冲突排查；历史项目故障、企业专有依赖或复杂编译问题需要先诊断再单独报价。

**Q：支持 Windows 和 Linux 吗？**
A：可咨询这两类设备，但必须根据具体系统版本、硬件和可用权限确认。当前只取得 Linux 现有环境基础检查证据；Windows 完整交付尚未验收，正式上架前需准确限定可承诺的系统。

**Q：Docker、数据库、GPU 这些包含吗？**
A：不在 ¥99 / ¥199 的默认范围内。¥399 也需要明确选中的扩展项及前提；Docker 专项未通过本轮实验验收，不能宣传为已验证服务。

**Q：远程协助要把密码交给你吗？**
A：不需要。远程授权由客户自己确认，密码、授权码和敏感信息由客户自行输入；如有系统变更先确认备份和风险。

**Q：服务做不成怎么办？**
A：先记录已完成工作、受限原因和未达验收项，按双方合法约定及实际平台规则处理变更、停止服务、退款或争议，不用一句“虚拟商品不退款”代替平台规则。
