## 3. 包含的事项

- 安装或配置合法来源的约定开发工具与依赖
- Node.js 项目优先使用 pnpm；Java/Python 分别按项目要求安装配套工具
- 记录工具版本、PATH 或环境变量，并用 Hello World 或双方指定的最小项目验证

## 4. 不包含事项

- 电脑操作系统重装、磁盘分区、数据迁移
- 企业私有仓库的复杂构建故障、历史项目无限兼容
- GPU 驱动、AI 大模型下载、远程公司内网/代理服务的违规配置

## 5. 客户下单前需要提供什么？

- Windows/Linux 版本、处理器、内存、硬盘空间与网络条件

- 允许安装的软件清单、管理员授权与备份确认
