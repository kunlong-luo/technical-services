## 接单原则

1. 对每项服务明确交付边界、验收标准、数据风险、授权范围与价格构成。
2. 不将未验证的测试、仿真 Demo 或仓库说明宣传为已上线客户生产环境。
3. 不承接未经授权访问、破解与盗版、绕过许可、危险工业控制等业务。
4. 生产环境改动需经授权并约定备份、回滚、维护窗口与验收。
5. 仅公布经许可的脱敏案例；不在仓库存储客户密钥、隐私数据或个人联系方式。

独立站域名、询盘表单及平台商品仍在规划与实施中。本仓库内容可用于需求咨询，但不能理解为已经上线的支付/交易系统；对外收费以正式约定的交付范围为准。
